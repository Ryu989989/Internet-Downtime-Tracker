Monitoring

Registers this app to run at sign-in (current exe path). Prefer the installed Setup build, or keep the portable .exe in a fixed folder — don’t move/rename it after enabling.

On (default): the X button and minimize hide the dashboard to the tray — monitoring keeps running. Use tray → Quit to exit. Off: minimize stays on the taskbar; closing the window quits the app.

Probe targets

Dashboard runs inside the app (no localhost port). DNS/HTTP checks run only when LAN+WAN are up, and are skipped while paused or during a speed test.
